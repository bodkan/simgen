Between-population statistics

Theme of this chapter

In this chapter, we will move from computing “within-group” population genetic statistics to “between-group” statistics. In a couple of practical exercises, we will implement “recipes” showcasing how simulation-based exploration allows us to characterize the expected behavior of statistics of interest under various relevant demographic scenarios to confidently understand their strengths and limitations. In the process, we will (re-)discover a couple of known features of \(F_{ST}\) and \(f_3\) statistics highly relevant for practical research.

Literature

  • Chapter 2.4, “2.4 Genetic drift in structured populations.”: As mentioned in the introduction, to do the exercises in this chapter, you don’t have to know more about \(F_{ST}\) other than that it’s a frequently useful metric of genetic differentiation between two populations scaled between 0 (no differentiation, i.e. both groups form a single panmictic population) to 1 (complete differentiation without any shared genetic variation betweeen the two groups). Still, if you want to know a bit more about the technical details (and many, many caveats) of \(F_{ST}\), take a look at the linked chapter of the book “An Owner’s Guide to the Human Genome”, specifically section titled “Measuring population structure: FST”.

  • If you want to know much more technical background into \(f_3\) statistics (introduced in this chapter), and \(f_4\) statistics and admixture proportion estimators \(f_4\)-ratio (introduced in the following chapter), you can take a look at the following papers: Peter, 2016, Lipson 2020, and Patterson et al., 2008.

Exercise 1: Recap on working with R lists and nested vectors

In the previous chapter, you learned to compute within-group summary statistics which is done by providing single vectors of individual names (most easily obtained by the function ts_names()) to various slendr functions in a very straightforward way.

Whenever we work with “between-group statistics” (statistics based on comparisons of genomic variation between different groups of individuals, also known as “multi-way statistics”in tskit which slendr uses as an internal statistical computation engine), we need to be aware of a couple of things with regards to how R handles nested lists of vectors.

Let’s first set up a small model to demonstrate this concept again and to practice it in an easy-to-understand context.

Start by creating a new R script called split_simulation.R and program the three-population model (populations called “outgroup”, “X”, and “Y”) in the following sketch in this script. Simulate a tree sequence object ts (sequence length 10Mb, recombination rate 1e-8, mutation rate 1e-8) from this model, scheduling the recording of ten individuals from each of the three populations at time 0 (i.e., the “present-day”).

Hint: As a gentle reminder, unlike our previous toy examples, this model features multiple populations, so you will need to program population splits. Remember that you can specify that a population should split from some parent lineage by using the population(..., parent = <parent population>) format.

Exercise 2: “Outgroup” \(f_3\) statistic

The \(f_3\) statistic is a famous population genetic metric formally established by Nick Patterson and David Reich in 2008. In practice, the statistic is used in two formulations:

  • as a measure of shared drift between two populations (also known as the “outgroup” \(f_3\) formulation), or

  • as an admixture test (also known as the “admixture \(f_3\)” formulation, something we’ll look at later).

As the name implies, \(f_3\) statistic involves the specification of three different lineages (usually populations, or groups of samples from those populations) often called A, B, and C in various mathematical equations, making it a good starting example of how to compute multi-population statistics in slendr

Let’s develop a simulation-based model which will allow us to explore some practically relevant features of this important summary statistic.

Let’s start by doing a couple of modifications to our script split_simulation.R:

  1. Wrap the code in a function called simulate_split() and update it so that this function accepts a single argument tsplit and uses it to specify the point at which point will the “X” and “Y” populations split from the “outgroup” lineage (instead of having a fixed value for the split time as you have now).

  2. Add the computation of the outgroup \(f_3\) statistic, using the function ts_f3(), setting the “X” individuals as the B = argument, “Y” individuals as the C = argument, and the A = argument to the “outgroup” individuals (remember to use the samples variable produced by ts_names() to do this).

  3. The function should return a data frame produced by the ts_f3() function, with a new column named tsplit containing the value of this function argument.

As you see, this is similar to what we did in the previous chapter and over time, you will recognize this as common pattern in simulation-based inference and computer programming in general.

Note: The \(f_3\) statistic is traditionally expressed as \(f_3(A, B; C)\), where C represents the outgroup. Unfortunately, in tskit the outgroup is named A, with B and C being the pair of samples from which we trace the length of branches towards the outgroup, so the statistic is interpreted as \(f_3(B, C; A).\)

NoteClick to see the solution

Here’s the content of the script split_simulation.R:

library(slendr)
init_env()

simulate_split <- function(tsplit) {
  outgroup <- population("outgroup", N = 1000, time = 10000)
  X <- population("X", N = 1000, time = tsplit, parent = outgroup)
  Y <- population("Y", N = 1000, time = tsplit, parent = outgroup)
  
  model <- compile_model(list(outgroup, X, Y), generation_time = 1)
  
  schedule <- schedule_recording(model, times = 0, list("each", 10))
  
  ts <-
    msprime(model, sequence_length = 10e6, recombination_rate = 1e-8, schedule = schedule) %>%
    ts_mutate(mutation_rate = 1e-8)

  samples <- ts_names(ts, split = TRUE)
  
  df <- ts_f3(ts, A = samples["outgroup"], B = samples["X"], C = samples["Y"])
  df$tsplit <- tsplit
  
  return(df)
}

Exercise 3: Statistical power of \(F_{ST}\) vs outgroup \(f_3\)

Another statistic which is very frequently used as a measure of population differentiation is \(F_{ST}\). Let’s say we want to understand which of the two statistics (\(f_3\) or \(F_{ST}\)) is more robust to \(N_e\) differences between the two populations under study.

Recall that \(N_e\) determines the amount of genetic drift (and, therefore, the rate of the loss) of genomic variation in a population. In other words, if you were interested in measuring how far in the past two populations began differentiating, would both of them give you a reliable answer, regardless of the \(N_e\) of those populations under study?

Both \(F_{ST}\) and \(f_3\) are routinely used as measures of population differentiation—can we use them equivalently? Does one have potentially more statistical power than the other? They are sometimes used quite interchangeably in practical research—could it sometimes be a problem?

We want to evaluate the impact of \(N_e\), so let’s modify our function simulate_split() a little bit first:

  1. Right now the function accepts a single argument tsplit. Add a second argument to this function called Ne, then modify the two lines of code programming the splits of X and Y populations from the outgroup and change the fixed values of N = 1000 to use the new flexible parameters Ne.

  2. Modify the function so that it returns in the resulting data frame not only containing the \(f_3\) value (computed by ts_f3()) but also the \(F_{ST}\) value (computed by ts_fst()). You can look up the help in ?ts_fst to see how to use this function.

  3. The data frame returned by the function should now include not only the tsplit column (containing the value of the tsplit argument) as well as the column Ne (containing the value of the Ne argument).

Finally, run the code for the function in your R console, then test it on a couple of tsplit and Ne parameter values.

NoteClick to see the solution

Here’s how the modified function looks like. Hopefully this is starting to look like a routine for you (because this is where we eventually want to get):

simulate_split <- function(tsplit, Ne) {
  # create a generalized demographic model
  outgroup <- population("outgroup", N = 1000, time = 10000)
  X <- population("X", N = Ne, time = tsplit, parent = outgroup)
  Y <- population("Y", N = Ne, time = tsplit, parent = outgroup)
  model <- compile_model(list(outgroup, X, Y), generation_time = 1)
  
  # program recording of individuals from each model and simulate their
  # genomic sequences
  schedule <- schedule_recording(model, times = 0, list("each", 10))
  ts <- msprime(model, sequence_length = 10e6, recombination_rate = 1e-8, schedule = schedule) %>%
    ts_mutate(mutation_rate = 1e-8)

  # compute Fst and f3 statistics
  samples <- ts_names(ts, split = TRUE)
  value_fst <- ts_fst(ts, sample_sets = samples[c("X", "Y")])$Fst
  value_f3 <- ts_f3(ts, A = samples["outgroup"], B = samples["X"], C = samples["Y"])$f3

  # compose the resulting data frame
  df <- data.frame(statistic = c("Fst", "f3"), value = c(value_fst, value_f3))
  df$tsplit <- tsplit
  df$Ne <- Ne
  
  return(df)
}

Conclusion: the \(f_3\) statistic really is an unbiased estimator of population divergence with respect to \(N_e\) of the two lineages. On the other hand, \(F_{ST}\) is not a great metric of a population split, even though it’s sometimes colloquially used in this phylogenetic sense.

However, to be fair, this is not surprising, because \(F_{ST}\) measures population differentiation! If the \(N_e\) is huge, both X and Y lineages can retain most of the genomic variation which arose in their ancestor (unless they diverged a very long time ago). On the other hand, \(f_3\) truly measures the shared branch length which is, by definition, accurately indicative of the population divergence.

simulate_split <- function(tsplit, Ne) {
  # set up the three-population demographic model
  outgroup <- population("outgroup", N = 1000, time = 10000)
  X <- population("X", N = Ne, time = tsplit, parent = outgroup)
  Y <- population("Y", N = Ne, time = tsplit, parent = outgroup)

  df <- data.frame(statistic = c("Fst", "f3"), value = c(value_fst, value_f3))
  df$tsplit <- tsplit
  df$Ne <- Ne
  
  return(df)
}

Exercise 4: “Admixture” \(f_3\)

Our primary interest in this exercise will be to investigate the limits of \(f_3\) to detect evidence of admixture—in particular, if we see a “non-significant” \(f_3\) statistic (“admixture \(f_3\)” is considered statistically not significant when it has a positive value), which factors could make this test being a false negative?

simulate_admixture <- function(tmix, prop, Ne) {
  outgroup <- population("outgroup", N = 5000, time = 10000)
  x <- population("x", N = 5000, time = 5000, parent = outgroup)
  y <- population("y", N = 5000, time = 5000, parent = outgroup)

  # in this generalized model, admixture parameters for the mixed
  # population are parametrized as tmix, prop, and Ne
  mix <- population("mix", N = Ne, time = tmix + 1, parent = x)
  gf <- gene_flow(from = y, to = mix, start = tmix, end = tmix - 1, proportion = prop)
  
  model <- compile_model(list(outgroup, x, y, mix), gene_flow = gf, generation_time = 1)

  schedule <- schedule_recording(model, times = 0, list(x, 20), list(y, 20), list(mix, 20))

  ts <- msprime(model, sequence_length = 25e6, recombination_rate = 1e-8, schedule = schedule) %>% ts_mutate(mutation_rate = 1e-8)

  samples <- ts_names(ts, split = TRUE)

  ts_f3(ts, A = samples["mix"], B = samples["x"], C = samples["y"]) %>%
    mutate(tmix = tmix, prop = prop, Ne = Ne)
}
